# ICU4X data markers baked into the blobs in this directory.
#
# Derived as the union of two sources, intersected with the markers the datagen
# in build_icu4x_data.sh supports:
#
#   1. `icu4x-datagen --markers-for-bin <a linked mozjs test binary>`. This
#      matches marker name strings, so it finds attribute-keyed lookups such as
#      collation tailorings and segmenter dictionaries, and misses singletons
#      that the compiler inlines under `compiled_data`. It is a lower bound.
#   2. `provider::MARKERS` from each ICU4X crate mozjs-sys links: icu_properties,
#      icu_locale, icu_casemap, icu_calendar, icu_time, icu_segmenter, and the
#      vendored icu_collator and icu_normalizer.
#
# To refresh after an ICU4X update, re-run `--markers-for-bin` against a binary
# built with the buffer provider. Every lookup goes through the provider there,
# so the marker names are all present and the result is exact.
#
# SegmenterDictionaryAutoV1 is the Chinese and Japanese word dictionary. It goes
# in the separate overlay blob that the `segmenter-cjk` feature adds, never in
# the main one.
#
# Not included: CalendarJapaneseExtendedV1, which icu_calendar declares but no
# datagen emits. It backs the `japanext` calendar, which Temporal does not
# expose.
